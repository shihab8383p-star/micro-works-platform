### **STEP 2: Get Reddit API Keys (FREE - 5 minutes)**

1. Go to: **https://www.reddit.com/prefs/apps**
2. Click **"Create App"** or **"Create Another App"**
3. Fill form:
   - **Name:** MicroWorks Bot
   - **App type:** Select **"script"**
   - **Description:** Auto-poster bot
   - **About URL:** Your website URL
   - **Redirect URI:** http://localhost:8080
4. Click **"Create app"**
5. **Copy these values:**
   - **Client ID:** (under app name)
   - **Client Secret:** (shown in form)

### **STEP 3: Get Twitter API Keys (FREE - 10 minutes)**

1. Go to: **https://developer.twitter.com/en/portal/dashboard**
2. Click **"Sign up"** (or login)
3. Click **"Create Project"**
4. Project name: **"MicroWorks Bot"**
5. Use case: **"Making a bot"**
6. Click **"Create App"**
7. **Copy these keys:**
   - API Key
   - API Secret Key
   - Access Token
   - Access Token Secret

---

### **STEP 4: Add Keys to GitHub (2 minutes)**

1. Go to your GitHub repo: **https://github.com/shihab8383p-star/micro-works-platform**
2. Click **"Settings"** tab
3. Click **"Secrets and variables"** > **"Actions"**
4. Click **"New repository secret"**

**Add these 6 secrets:**

| Secret Name | Value |
|-------------|-------|
| `REDDIT_CLIENT_ID` | Your Reddit Client ID |
| `REDDIT_CLIENT_SECRET` | Your Reddit Client Secret |
| `REDDIT_USERNAME` | Your Reddit username |
| `REDDIT_PASSWORD` | Your Reddit password |
| `TWITTER_API_KEY` | Your Twitter API Key |
| `TWITTER_API_SECRET` | Your Twitter API Secret |

---

### **STEP 5: Enable GitHub Actions (1 minute)**

1. Go to **"Actions"** tab in your GitHub repo
2. Click **"I understand my workflows, go ahead and enable them"**
3. Done! Automation is now active!

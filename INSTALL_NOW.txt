📥 STEP 1: DOWNLOAD (1 minute)
═════════════════════════════════════════════════════════════════════════════

   1. Open this link in your browser:
   
      👉 https://www.mongodb.com/try/download/community
   
   2. You'll see a download form. Select:
   
      Version:   7.0.x (Current)
      Platform:  Windows
      Package:   msi
   
   3. Click the BIG GREEN "Download" button
   
   4. Wait for download (300-400 MB)
      File: mongodb-windows-x86_64-7.0.x-signed.msi


═════════════════════════════════════════════════════════════════════════════

🔧 STEP 2: INSTALL (2 minutes)
═════════════════════════════════════════════════════════════════════════════

   1. Double-click the downloaded .msi file
   
   2. Click "Next" on welcome screen
   
   3. Accept license → Click "Next"
   
   4. Choose "Complete" installation → Click "Next"
   
   5. Service Configuration (KEEP ALL DEFAULTS):
      ✅ Install MongoDB as a Service  ← IMPORTANT!
      ✅ Run service as Network Service user
      ✅ Service Name: MongoDB
      
      Click "Next"
   
   6. MongoDB Compass:
      ✅ Install MongoDB Compass (optional but useful)
      
      Click "Next"
   
   7. Click "Install" → Wait 1-2 minutes
   
   8. Click "Yes" on security prompt
   
   9. Click "Finish"


═════════════════════════════════════════════════════════════════════════════

✅ STEP 3: VERIFY (1 minute)
═════════════════════════════════════════════════════════════════════════════

   1. Open Command Prompt (press Windows + R, type "cmd", press Enter)
   
   2. Type this command and press Enter:
   
      mongod --version
   
   3. You should see:
   
      db version v7.0.x
      Build Info: ...
      
      ✅ SUCCESS! MongoDB is installed!

🐛 QUICK TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════════

   Problem: "mongod is not recognized"
   Solution: Close and reopen Command Prompt, then try again
   
   Problem: Installation fails
   Solution: Right-click installer → "Run as administrator"
   
   Problem: Service won't start
   Solution: Open services.msc → Find MongoDB → Click Start

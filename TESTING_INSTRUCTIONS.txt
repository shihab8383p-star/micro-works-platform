🗄️ STEP 1: SETUP MONGODB (Required - One Time)
===============================================

OPTION A: MongoDB Atlas (Recommended - Easy & Free)
---------------------------------------------------
1. Go to: https://www.mongodb.com/cloud/atlas/register
2. Create free account (no credit card needed)
3. Create free cluster (M0 tier) - takes 3-5 minutes
4. Create database user:
   - Username: admin
   - Password: admin123
5. Setup network access:
   - Click "Allow Access from Anywhere"
6. Get connection string:
   - Click "Connect" → "Connect your application"
   - Copy the string
7. Update .env file:
   - Replace MONGODB_URI with your connection string
   - Example:
     MONGODB_URI=mongodb+srv://admin:admin123@cluster0.xxxxx.mongodb.net/microjob-platform?retryWrites=true&w=majority

📄 See: MONGODB_ATLAS_SETUP.md for detailed guide

OPTION B: Local MongoDB (Advanced)
-----------------------------------
1. Download from: https://www.mongodb.com/try/download/community
2. Install MongoDB on Windows
3. Start MongoDB service
4. Keep default .env settings (already configured)

🐛 TROUBLESHOOTING
==================

Problem: Cannot connect to MongoDB
Solution: 
   1. Check MongoDB Atlas is set up correctly
   2. Verify .env file has correct connection string
   3. Check internet connection
   4. See MONGODB_ATLAS_SETUP.md

Problem: Port 5000 already in use
Solution:
   1. Stop other process on port 5000
   2. Or change PORT=3000 in .env file

Problem: Module not found
Solution:
   Run: npm install

Problem: JWT error / Unauthorized
Solution:
   1. Clear browser cache
   2. Open DevTools (F12) → Application → Local Storage → Clear
   3. Login again

Problem: Jobs not appearing
Solution:
   Run: npm run init-db
